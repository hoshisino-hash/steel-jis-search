# 昇降機検査員クエスト — デプロイ & 開発メモ

昇降機等検査員 修了考査(BEEC)対策のゲーム型 学習PWAです。
法令・告示の数値・規定(著作権の対象外/著作権法13条)に基づく自作問題のみを収録。
オフライン動作・スマホのホーム画面インストールに対応します。

----------------------------------------------------------------------
## ファイル構成
```
elevator-inspector/
├── index.html              アプリ本体(HTML+CSS+ゲームエンジンJS)
├── data/
│   └── questions.js        問題バンク(window.QB)。告示改正時はここだけ差し替え
├── manifest.json           PWA設定
├── service-worker.js       オフライン動作(CACHE_VERSION を上げると更新反映)
├── icon-192.png / icon-512.png / icon-maskable-512.png / apple-touch-icon.png
└── README.txt              このファイル
```
※ index.html はデータを `<script src>` で読むため、ローカルでファイルをダブルクリック
   (file://)しても fetch 不要で動作します。

----------------------------------------------------------------------
## ゲーム内容(モード)
- 本番模試 30問   … R7実測の分野配分。20問正解で合格。30分タイマー付き
- 弱点復習(SRS)  … 間違えた問題を最適間隔(SM-2簡易)で再出題
- 判定チャレンジ  … 「要是正/要重点点検/指摘なし」を即断する実務形式
- 数値フラッシュ  … 頻出数値の暗記カード(タップで裏返し・自己採点)
- 計算ドリル      … フックの法則 / 同期速度 / オームの法則 / 曲げM を無限自動生成
- 分野別トレーニング … 9分野から選択
- 要点ノート(📖)… 検索付きチートシート。持込可の考査を想定し「どこに何が
                     書いてあるか」を素早く引く練習(数値・告示番号を一次情報で整理)

ゲーミフィケーション:
- 正解でエレベーターが屋上(=合格)へ上昇。XP・6段階ランク(見習い→マスター検査員)
- 連続正解コンボ(急行運転)、デイリーミッション、連続学習日数、9種バッジ、分野別正答率

## デプロイ(Cloudflare Pages)
このフォルダ(elevator-inspector/)の「中身」をプロジェクトのルートとして公開します。

[A] 手動アップロード(最も簡単)
1. https://dash.cloudflare.com → Workers & Pages → Create → Pages → Upload assets
2. プロジェクト名(例: elevator-inspector)を入力 → Create project
3. elevator-inspector フォルダ内の index.html / manifest.json / service-worker.js /
   data フォルダ / 各 *.png を「まとめて」ドラッグ&ドロップ(data はフォルダごとでOK)
4. Deploy site → 数分で https://elevator-inspector.pages.dev が発行される

[B] GitHub連携
- Connect to Git → このリポジトリを選択
- ビルド設定: フレームワークなし / ビルドコマンド空 / 出力ディレクトリ「elevator-inspector」

----------------------------------------------------------------------
## スマホへのインストール
- iPhone/iPad: Safariで開く → 共有 → 「ホーム画面に追加」
- Android: Chromeで開く → ︙ → 「アプリをインストール」
初回はオンラインでキャッシュ作成。2回目以降オフライン可。

----------------------------------------------------------------------
## 更新手順
- 問題を増やす/数値を直す: data/questions.js を編集(window.QB の questions / flashcards)
- 反映を強制: service-worker.js の CACHE_VERSION を上げて再デプロイ
- 利用者は次回起動時に自動更新(Service Workerのキャッシュ機構)

----------------------------------------------------------------------
## 著作権・正確性の注意
- 収録問題は法令・告示の数値に基づく自作。BEECの考査問題・テキスト文面は不収録
- 数値は令和7年7月1日施行の改正告示に準拠して作成。実務では必ず原典
  (建築基準法・施行令・各告示・定期検査業務基準書)を確認すること
- 学習記録は端末ローカル(localStorage)に保存。記録画面からエクスポート可能

# QRセーフティボイス — 現場QR注意喚起・対面記録 PWA

日立ビルシステムの「重要箇所にQRコードを設置し、カメラが読み取ると
注意喚起の音声が流れる+向き合った記録を残す」仕組みを、
スマホ1台で完結する形で再現したプロトタイプです。

## 仕組み

1. 「地点」タブで危険箇所・重要箇所を登録(地点名/注意メッセージ/危険度)
2. 地点ごとにQRコードが発行される → 印刷して現場に貼付
   QRには地点名・注意メッセージ・危険度がそのまま入っている(自己完結型/QSA2形式)ため、
   **どの端末のアプリで読み取っても登録不要で音声喚起でき、読んだ端末に自動登録**される。
   URLを共有するだけで複数人運用が可能(サーバー不要のまま)。
   ※ 旧形式(QSA:ID)のQRは印刷した端末でのみ動作。印刷し直しを推奨
3. 「スキャン」タブでカメラ起動 → QRにかざすと
   - 警告音(ビープ)+ 注意メッセージの音声読み上げ(Web Speech API)
   - 画面の赤フラッシュ+バイブレーション
4. 設定した秒数(既定3秒)QRに向き合い続けると「確認完了」として記録
5. 「記録」タブで対面履歴(日時/地点/対面秒数/確認完了か)を確認、CSV出力可

本家システムとの違い:
- 本家はヘルメット/胸部装着カメラで常時ハンズフリー読み取り+サーバー集約
- 本アプリはスマホのカメラを使い、記録は端末内(localStorage)に保存
  ※ スマホを胸ポケットに挿してカメラを外に向ければ疑似ハンズフリー運用も可能
- カメラ映像は端末内で処理され、外部送信は一切ありません(オフライン動作)

## ファイル構成

```
qrsafety/
├── index.html              アプリ本体(HTML+CSS+JS)
├── jsQR.js                 QRコード読み取りライブラリ(jsQR v1.4.0, Apache-2.0)
├── qrcode.js               QRコード生成ライブラリ(qrcode-generator v1.4.4, MIT)
├── qrcode_UTF8.js          同ライブラリのUTF-8エンコーダ(日本語をQRに格納)
├── manifest.json           PWA設定
├── service-worker.js       オフライン動作
├── icon-192.png            アイコン(192x192)
├── icon-512.png            アイコン(512x512)
├── icon-maskable-512.png   Android用マスカブルアイコン
└── apple-touch-icon.png    iOS用アイコン(180x180)
```

## デプロイ(Cloudflare Pages / GitHub Pages)

鋼材JIS早見表と同じ手順です。上記9ファイルを
Cloudflare Pagesにドラッグ&ドロップするだけで公開できます。
(手順の詳細はリポジトリ直下の README.txt を参照)

重要: カメラ(getUserMedia)は HTTPS でしか動きません。
Cloudflare Pages / GitHub Pages はどちらもHTTPSなので問題ありません。
file:// で直接開いた場合、カメラは起動できません。

## 技術メモ

- QR検出: BarcodeDetector API(Android Chrome等はハードウェア支援で高速)
  → 非対応ブラウザ(iOS Safari等)は jsQR に自動フォールバック
- 音声: Web Speech API(speechSynthesis, ja-JP)+ WebAudioビープ
  ※ iOSは端末のマナーモード(消音スイッチ)ONだと読み上げが鳴らない場合あり
- 画面消灯防止: Screen Wake Lock API(対応端末のみ)
- 同一地点の再通知抑制: 既定60秒(設定で変更可)
- 記録は最大3000件を端末内に保持。CSV/JSONでエクスポート可能

## 運用のヒント

- QRは「QR一括印刷」からA4に印刷 → ラミネートして貼付が長持ちします
- 暗所ではQRを大きめ(1辺5cm以上)に印刷すると読み取りが安定します
- 記録CSVはKYT(危険予知訓練)記録や作業日報の添付資料に使えます

# 昇降機検査員クエスト — 昇降機等検査員 修了考査対策ゲーム

## 概要

昇降機等検査員講習の修了考査(四肢択一30問・20問正解で合格)対策の
学習ゲームアプリ(PWA)。スマホ前提・オフライン動作。

## ゲームモード

1. 模試モード(30問)
   R7年度修了考査の実測出題構成を再現:
   法令6 / 建築2 / 機械2(計算1) / 電気2(計算1) / 構造4 / 検査5 / 遊戯7 / 維持2
   20問以上で合格判定。分野別成績と間違い解説付き。

2. 数値即答モード
   「床先間距離は?」→4cm のような頻出数値を15秒以内に即答。
   スピードボーナスXPあり。

3. 判定シミュレーター
   検査結果の状況文を読んで「要是正/要重点点検/指摘なし」を判定。
   考査の最頻出形式を再現。

4. 計算ドリル
   フックの法則(F=EAΔL/L)・同期速度(N=120f/P)・オームの法則・
   実効値・線間電圧・はりの曲げモーメントを数値ランダムで無限生成。

5. 分野別特訓 — 8分野から選んで集中学習

6. 弱点復習(SRS) — 間違えた問題ほど高頻度で再出題

## ゲーム要素

- XP・レベル・称号(見習い検査員 → 伝説の検査員)
- コンボ・紙吹雪・効果音(WebAudio)・レベルアップ演出
- バッジコレクション(12種)
- 成績ノート(分野別正答率・模試履歴)

## ファイル構成

```
liftquest/
├── index.html              アプリ本体(HTML+CSS+JS)
├── data.js                 問題バンク(154問+自動生成)— 改正時はここだけ差替え
├── manifest.json           PWA設定
├── service-worker.js       オフライン動作(data.jsはnetwork-firstで即時更新)
├── icon-192.png / icon-512.png / icon-maskable-512.png / apple-touch-icon.png
└── README.txt              このファイル
```

## デプロイ(Cloudflare Pages)

steel-jis-search 本体と同じ手順。プロジェクトにこのフォルダの
ファイル一式をアップロードするか、リポジトリ連携の場合は
https://<project>.pages.dev/liftquest/ で公開される。

スマホへのインストール:
- iPhone: Safariで開く → 共有 → ホーム画面に追加
- Android: Chromeで開く → メニュー → アプリをインストール

## データ更新(告示改正時)

問題は data.js に JSON 形式で分離してある。
告示の判定基準値が改正されたら data.js の該当問題の数値・解説を
修正し、service-worker.js の CACHE_VERSION を上げて再デプロイ。

## 出題内容の根拠と著作権

- 問題はすべて 建築基準法・施行令・国交省告示(平20告示283/284/285/424号、
  平12建告1413/1414/1417/1423号 等。令和7年7月1日施行の改正対応)・
  国交省「昇降機の適切な維持管理に関する指針」・遊戯施設手引き等の
  「法令・告示の数値・規定」に基づく自作問題。
  法令・告示の条文は著作権法13条により著作権の対象外。
- BEECの考査問題・講習テキスト・業務基準書の文面は収録していない
  (出題傾向の分析にのみ利用)。公開しても著作権上安全な設計。

## 学習のヒント(本番対策)

- 本番は講習テキスト・電卓(通信機能なし)持込可。
  暗記より「どこに何が書いてあるか」の検索力+頻出数値の即答力が効く。
- 計算は毎年2問程度(フックの法則系・同期速度系)でパターン固定。
  計算ドリルで型を体に入れておけば確実に2点取れる。
- 判定問題は「要是正=基準不適合」「要重点点検=次回までに不適合の
  おそれ」の定義の使い分けが最頻出。判定シミュレーターで反復を。

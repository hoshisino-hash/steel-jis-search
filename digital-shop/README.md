# デジタル商品販売の仕組み — 運用ガイド

「楽して稼げる」は存在しませんが、**「最初に仕込めば、あとは販売・決済・納品が全自動で回る」仕組み**なら作れます。これはそのスターターキットです。

## この仕組みの全体像

```
[商品] 鋼材重量計算ツール(product/steel-weight-calculator.html)
   ↓ 出品
[販売所] BOOTH または Gumroad(決済・納品・再DLを全自動で代行)
   ↑ 誘導
[宣伝] ランディングページ(landing/index.html)+ SNS・既存アプリからのリンク
```

あなたが手を動かすのは「出品の初期設定」と「ときどきの宣伝」だけ。購入対応・ファイル送付・決済は販売プラットフォームが24時間自動でやってくれます。

## フォルダ構成

```
digital-shop/
├── README.md                          このガイド
├── product/
│   └── steel-weight-calculator.html   商品第1号(これ自体が販売物)
└── landing/
    └── index.html                     販売ランディングページ(Cloudflare Pagesで公開)
```

## なぜ「鋼材重量計算ツール」なのか

- あなたには既に「鋼材JIS早見表」を作って職場に配った実績がある = **同じ悩みを持つ人が確実に存在する市場**
- 単一HTMLファイルなので在庫ゼロ・配送ゼロ・サポートほぼゼロ
- 「規格表に載っていない寸法の重量を出したい」は現場の普遍的ニーズ
- 早見表アプリ(無料)→ 重量計算ツール(有料)という自然な導線が作れる

## セットアップ手順(初回のみ・合計1〜2時間)

### Step 1: 商品の最終確認(10分)

1. `product/steel-weight-calculator.html` をブラウザで開く
2. スマホでも開いて動作確認(数値を入れて計算されるか)
3. 必要なら形状・材質を追加(Claudeに頼めばOK)

### Step 2: BOOTHに出品(30分)

BOOTH(pixiv運営)が日本語・日本の銀行振込対応で一番簡単です。

1. https://booth.pm でアカウント作成(pixivアカウントが必要)
2. 「ショップ開設」→ ショップ名を決める(例: 「現場ツール工房」)
3. 「商品登録」→「ダウンロード商品」を選択
4. `steel-weight-calculator.html` をZIPにしてアップロード
   - ZIPには簡単な `使い方.txt` を同梱すると親切
5. 商品説明文は `landing/index.html` の文面をコピペして整形
6. **価格: ¥300〜¥500 推奨**(ワンコインは衝動買いされやすい)
7. 売上の振込先口座を登録

> 手数料: BOOTH はダウンロード商品 5.6% + ¥22/件。¥500で売ると約¥450が手元に残ります。

### Step 3: ランディングページを公開(20分)

既存アプリと同じ手順(リポジトリ直下の README.txt 参照)で Cloudflare Pages にデプロイできます。

1. `landing/index.html` 内の3箇所の `TODO` コメントを埋める
   - 購入ボタン2箇所の `href="#"` → BOOTHの商品ページURL
   - フッターの屋号・連絡先
2. Cloudflare Pages に新プロジェクトとしてアップロード(例: `genba-tools.pages.dev`)

### Step 4: 導線をつなぐ(15分)

ここが一番効きます。**既存の無料アプリ(鋼材JIS早見表)に1行リンクを足す**:

```html
<!-- index.html のフッター付近に追加する例 -->
<a href="https://booth.pm/ja/items/XXXXX">⚖️ 重量計算ツール(有料版)はこちら</a>
```

無料の早見表を使っている同僚・同業者が、そのまま見込み客になります。

### Step 5: 宣伝(継続・週10分程度)

- X(Twitter)で「#製造業」「#町工場」タグを付けてスクリーンショット付きで投稿
- 職場で早見表のQRコードを配った掲示物に、有料ツールの案内を1行追加

## 現実的な収益の見込み(正直ベース)

| 状態 | 月の売上目安 |
|---|---|
| 出品しただけ(宣伝なし) | 0〜数百円 |
| 無料アプリからの導線あり+月数回のSNS投稿 | 数百〜数千円 |
| 商品が3〜5個に増え、固定ファンがつく | 数千〜数万円 |

最初の1個で生活は変わりません。**勝ち筋は「現場系マイクロツール」を量産してカタログ化すること**です。1個あたりの制作はClaudeに頼めば1日かからないので、「企画→検収→出品」だけに集中できます。

## 商品ラインナップの拡張アイデア(第2号以降)

需要が近い順:

1. **ボルト・ナット規格早見+締付トルク計算**(早見表アプリの有料拡張版)
2. **テーパー・勾配・三角関数計算機**(機械加工向け)
3. **塗装面積・塗料量計算ツール**
4. **溶接脚長・のど厚計算ツール**
5. **現場帳票テンプレート集**(Excel: 検査成績書・出荷案内など)

## 法律・規約の注意(必読)

- **特定商取引法**: 個人がBOOTH/Gumroadで売る場合、表記義務の大部分はプラットフォームの仕組みでカバーされますが、BOOTHでは「特定商取引法に基づく表記」の設定画面があるので必ず入力してください。
- **確定申告**: 副業所得が年20万円を超えたら確定申告が必要です(住民税は20万円以下でも申告要)。売上はスプレッドシート等で記録しておくこと。
- **就業規則**: 勤務先の副業規定を確認してください。
- **免責**: 計算ツールは「参考値」である旨を商品説明に明記する(ランディングページには記載済み)。吊り荷重など安全に関わる用途での誤用リスクに備えるためです。

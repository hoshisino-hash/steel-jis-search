## 0. なぜ「薄明」なのか（タイトルの由来）

「薄明（はくめい）」は、日の出前と日没後の、空がほのかに明るい時間帯を指す言葉。
天文学的にも **朝の薄明** と **夕の薄明** の両方を意味する。
ユーザー要望の「黄昏時（夕）と東雲（暁）が入り混じったノスタルジックな世界観」を
一語で言い当てるため、これをタイトル兼コンセプトの軸に据える。

> 朝でも夜でもない、境界の時間。
> 一日のどこにも属さない、誰のものでもない静かな時間を、彼女と二人で過ごす。

## 3. 世界観・ビジュアル

### 3.1 情景

薄明の書斎。古い木の机、窓辺、窓の外には黄昏と東雲が溶け合った空。
一番星、遠い街明かり、ゆっくり流れる雲。時間が曖昧で、ノスタルジック。

### 3.2 配色パレット（CSS変数の素案）

薄明（黄昏×東雲）を表現する、紫紺・茜・藍・金のグラデーション。

```css
:root {
  /* 空（薄明グラデーション） */
  --sky-top:    #1b2240;  /* 藍（夜寄り・天頂） */
  --sky-mid:    #4a3a63;  /* 紫紺 */
  --sky-low:    #8a5a6a;  /* 薄紅 */
  --sky-horizon:#d99a6c;  /* 茜・地平の残光 */

  /* 室内・UI */
  --ink:        #f3eee6;  /* 文字（淡い生成り） */
  --ink-dim:    #b9b2a8;
  --wood:       #2a2320;  /* 机・木部 */
  --panel:      #1d1a24;  /* パネル背景（半透明で重ねる） */
  --line:       #3a3442;

  /* アクセント */
  --star:       #f5e6b8;  /* 一番星・金 */
  --accent:     #c9788a;  /* 薄紅アクセント */
  --accent-cool:#6f7fb0;  /* 藍アクセント */
}
```

### 3.3 時間帯による空の移ろい

- **自動モード**: 端末時刻と連動。明け方は東雲寄り（茜→藍が下から上へ）、
  夕方は黄昏寄り（上から藍が降りる）にグラデーションを補間。
- **固定モード**: 「黄昏」「東雲」「真夜」をユーザーが選んで固定。
- 実装は CSS の `linear-gradient` のカラーストップを JS で時間補間し、
  `requestAnimationFrame` ではなく数十秒〜数分間隔でゆっくり更新（省電力）。

## 4. コアループ / メカニクス（v1）

```
起動 → 薄明の書斎に宵がいる（佇まい・呼吸・まばたき）
  │
  ├─ 環境音ミキサーで好みの音を作る（雨・風・焚き火・時計・波…）
  │
  └─ 「作業開始」を押す
        → 宵も書きものを始める（作業中ステート）
        → 不定期に万年筆の筆記音・ページめくり音が環境音に混ざる
        → 一定時間ごとに小休止演出（伸び・窓を見る）
        → 「作業終了」で宵も筆を置く（見守り／就寝ステート）
```

操作は最小限。基本は「置いておく」だけで情景と音が続く。

## 6. 環境音エンジン設計（F4 / Web Audio）

### 6.1 方針

音声ファイルを一切持たず、**ノイズ生成＋フィルタ＋LFO＋ランダムイベント**で
全ての環境音を合成する。これにより：

- ファイルサイズ ≒ 0（コードのみ）
- ライセンス完全フリー（素材を使わない）
- オフライン完全動作・無限ループでも継ぎ目なし

### 6.2 基本ビルディングブロック

```
[ノイズ源] → [BiquadFilter] → [レイヤーGain] → [マスターGain] → 出力
                 ↑                 ↑
              [LFO]            (ミキサーのスライダー)
```

- **ノイズ源**: `AudioBufferSourceNode`（loop=true）に
  - ホワイトノイズ：乱数で-1〜1を充填
  - ピンクノイズ：Voss-McCartney 近似 or 1次フィルタ
  - ブラウンノイズ：積分（前値に微小乱数を加算しクリップ）
- **フィルタ**: `BiquadFilterNode`（lowpass/bandpass/highpass）で音色を決める
- **LFO**: 低速 `OscillatorNode` → `GainNode` で、フィルタ周波数や音量を
  ゆらす（風の唸り、波のうねり）
- **ランダムイベント**: `setTimeout`/`AudioContext.currentTime` スケジューラで、
  短いノイズバースト/クリックを不定間隔で鳴らす（雨粒、薪の爆ぜ、時計、筆記音）

### 6.3 レイヤー定義（v1の収録目標）

| レイヤー | 合成方法 |
| --- | --- |
| 雨 | ブラウン/ピンクノイズを lowpass、上に高音の雨粒ピン（短いbandpassバースト）を散布 |
| 風 | ブラウンノイズを lowpass、フィルタ周波数を超低速LFOでゆらす |
| 焚き火 | ブラウンノイズ（低）＋不定間隔の「爆ぜ」（短い高域バースト＋エンベロープ） |
| 波 | ピンクノイズの音量を超低速LFO（0.1Hz前後）でうねらせる |
| 時計（秒針） | 1秒周期の短いクリック（インパルス＋bandpass、左右交互で振り子感） |
| 夜の静けさ | 極低音量のブラウンノイズ＋ごく稀な「間」のアクセント（基調レイヤー） |
| 筆記音（万年筆） | 短いザリッというノイズバースト群。**宵の作業ステートに同期して鳴る** |
| ページめくり | まれな帯域スイープ（同上、ステート同期 or ランダム） |

> 筆記音・ページめくりは「コンパニオン演出（F2）」と「環境音（F4）」の
> **接続点**。作業中ステートのときだけ、彼女の手元から音が立つ＝
> 「隣に誰かがいる」感覚を、v1の2機能だけで成立させる肝になる。

### 6.4 ミキサー仕様（F5/F6）

- 各レイヤーに 0.0〜1.0 のスライダー。0 のときはノードを停止（CPU節約）。
- マスター音量スライダー。
- プリセット：現在のミックスを名前付き保存（例：「雨夜」「焚き火」「波と時計」）。
  初期プリセットを2〜3個同梱。
- **重要**: Web Audio はユーザー操作後でないと `AudioContext` を開始できない。
  最初の「作業開始」or 再生ボタンのタップで `audioContext.resume()` する。

## 7. コンパニオン演出設計（F2 / F3）

### 7.1 状態機械

```
 absent ──(起動/入室)──▶ idle(見守り) ──(作業開始)──▶ working(作業中)
    ▲                        │  ▲                          │
    │                        │  └──(小休止 数分ごと)──◀─ micro_break
    └──(退室/就寝)──◀────────┘                            │
                          break(休憩) ◀──(作業終了)────────┘
```

| ステート | 見た目／挙動 |
| --- | --- |
| idle（見守り） | 静かに座り、呼吸・まばたき。たまに窓の外を見る。 |
| working（作業中） | 手元で書きもの。筆記音が同期して鳴る。集中の姿勢。 |
| micro_break | 数分ごとに伸び／ひと息／髪を直す（数秒）→ working に戻る |
| break（休憩） | 筆を置き、ひと息。お茶など。空を眺める。 |
| absent / 就寝 | 退室 or 机に伏せる（長時間放置や夜間） |

### 7.2 描画方式

- **推奨：インラインSVG＋CSSアニメーション**。
  - パーツ分け（髪・顔・眼鏡・胴・腕・万年筆）してレイヤー化。
  - 呼吸＝胴のわずかな上下、まばたき＝瞼の `opacity`/`scaleY` を周期切替、
    髪揺れ＝ゆるい `transform` ループ、書く手＝小さな往復。
  - パレット（§3.2）の CSS変数でテーマと一体化できる利点。
- 代替：スプライト（PNG連番）切替。立ち絵を別途用意できる場合に。
- **`prefers-reduced-motion`** 対応：動きを止め、静止の佇まいにフォールバック。

### 7.3 v1の割り切り

- 立ち絵の作り込みは段階的に。まずは「呼吸・まばたき・書く手」の
  3アニメ＋4ステートで「生きている感」を最小コストで出す。
- セリフは固定1〜2種 or 無言。本格セリフ/関係構築は将来へ。

## 9. 技術アーキテクチャ

既存の姉妹アプリ（`/bolts`）と同一構成を踏襲：

```
tasogare/
├── index.html          アプリ本体（HTML＋CSS＋JS を単一ファイルに同梱）
├── manifest.json       PWA設定（standalone, portrait, theme_color=薄明）
├── service-worker.js   オフライン（cache名 tasogare-vX、キャッシュ優先）
├── icon-192.png        ／ icon-512.png ／ icon-maskable-512.png
└── apple-touch-icon.png
```

- **フレームワーク不使用**。素のHTML/CSS/JS（既存方針に一致）。
- **状態保存**は `localStorage`（既存アプリと同様、端末ローカル）。
- Service Worker は既存の `service-worker.js` をベースに cache名のみ変更。
  HTMLは network-first 寄り（既存の方針＝コード更新の即時反映）に合わせる。
- 既存トップ（鋼材JIS）の「姉妹アプリ登録」機能から相互リンクできるよう、
  公開後にURLを登録する想定（実装は将来）。

## 10. アクセシビリティ / パフォーマンス

- `prefers-reduced-motion`：アニメ・雲・空の移ろいを停止し静止画に。
- 音量0のレイヤーはノードを停止し、CPU/バッテリを節約。
- 空の更新はRAFを使わず低頻度ティック。タブ非表示時は更新・発音を絞る
  （`visibilitychange` で suspend）。
- 立ち絵SVGは軽量に保ち、初回描画を速く。
